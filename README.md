# 冗長電源基板（radundant_circuit V1.0）

2本のバッテリーから電源を取り込み、片方を外しても、残ったバッテリーから給電を続けるための基板です。ロボット搭載PCへの給電を想定しています。

本書は、リポジトリ内の回路図・PCBデータと設計メモをもとにしています。回路の接続は確認済みですが、実装状態・連続許容電流・PCの無停電動作は実機での確認が必要です。

## 接続構成

```text
バッテリー1 ＋ → J1(IN1) → F1 → D1の素子1 ─┐
                                             ├→ J3(OUT) → 外付けDC/DC → PC
バッテリー2 ＋ → J2(IN2) → F2 → D1の素子2 ─┘
バッテリー1・2の－、J3の－は共通GND
```

- 設計上の想定電池は **6S LiPo × 2本**（1本あたり公称22.2 V、満充電25.2 V）です。これは基板の動作保証範囲を示すものではありません。
- D1（RBQ30NS65ATL）の2つのダイオードで電源を合流します。基本的に電圧の高い側から給電され、電圧が近い場合は両方から流れることがあります。IN1を優先する制御はありません。
- OUTの電圧は、給電中の入力電圧からダイオードの電圧降下を引いた値になります。**この基板だけでは19 Vに変換・安定化しません。** PCには適切な外付けDC/DCを介して接続してください。
- バッテリー充電回路や、低電圧時に自動遮断する回路はありません。

## 端子と極性

PCB上のコネクタは、いずれも `AMASS_XT60-F_1x02_P7.20mm_Vertical` のフットプリントです。

| 端子 | 基板表示 | 用途 | 1番ピン | 2番ピン |
| --- | --- | --- | --- | --- |
| J1 | IN1 | バッテリー1入力 | GND（－） | バッテリー1の＋（F1の手前） |
| J2 | IN2 | バッテリー2入力 | GND（－） | バッテリー2の＋（F2の手前） |
| J3 | OUT | 外付けDC/DCの入力へ | GND（－） | 合流後の出力＋ |

ピン番号は回路図・PCBのパッド番号です。見る面によって左右が反転するため、コネクタの左右だけで極性を判断せず、PCBデータと実物の導通を確認してください。OUTへバッテリーを接続しないでください。

## LEDの見方

| LED | 対応抵抗 | 表示する電圧 |
| --- | --- | --- |
| D2 | R1 | IN1側のヒューズF1通過後の電圧 |
| D3 | R2 | IN2側のヒューズF2通過後の電圧 |
| D5 | R3 | OUTの電圧 |

LEDは電圧の有無の目安です。点灯だけでは、電池残量や、その入力から実際に負荷へ電流が流れているかは判断できません。R1～R3の値は図面では `R` のままなので、使用するLEDと最大電圧に合わせて抵抗値・許容損失を決めて実装してください。

## 初回使用前の確認

1. F1・F2に適切なヒューズを取り付けます。図面では容量未指定です。負荷電流、突入電流、配線・コネクタ・基板の許容電流に合わせて選定してください。
2. D1、TVSのD4、LED、電解コンデンサC1の向きと、はんだ付けを確認します。C1の1番ピンが＋、2番ピンがGNDです。
3. 電源を外した状態で各コネクタの極性と配線を確認し、はんだブリッジなどによる＋とGNDの短絡がないことを確認します。コンデンサ充電による一時的な導通表示と短絡を区別してください。
4. まず電流制限付き電源と小さな試験負荷で、IN1だけ・IN2だけの各条件でOUTに給電されることを確認します。
5. 外付けDC/DCの入力許容範囲と、PCに必要な出力電圧・極性・容量を確認します。設計メモには19 V出力を想定していますが、実際のPCの仕様を優先してください。
6. 想定負荷でダイオード・ヒューズ・コネクタ・配線の温度とOUT電圧を確認します。部品単体の電流定格を基板全体の連続許容電流として扱わないでください。

## 通常の使い方

1. 負荷の電源を切り、J3（OUT）を外付けDC/DCの入力へ接続します。
2. バッテリー1をJ1（IN1）へ、バッテリー2をJ2（IN2）へ接続します。
3. IN1・IN2・OUTの電圧を確認します。LEDを実装している場合は、D2・D3・D5の点灯も確認します。
4. DC/DCの出力がPCの指定電圧・極性になっていることを確認して、PCへの給電を開始します。
5. 使用中は両方の電池残量を別途監視します。本基板には過放電を防止する自動遮断機能はありません。

## 給電を続けながら電池を交換する

1. 残す側の電池が接続され、ヒューズが正常で、**その1本だけで負荷全体を動かせること**を確認します。
2. 交換する側の電池だけを外します。両方を同時に外さないでください。
3. 極性を確認した交換用電池を、空いた入力へ接続します。
4. 入力・出力電圧と、負荷が正常動作していることを確認します。

電池交換時の無停電動作は、残る電池の電圧・内部抵抗、負荷、DC/DCの特性に依存します。事前に試験負荷で切替時のOUT電圧低下とDC/DCの出力を確認し、その後PCで停止・再起動しないことを確認してください。C1があることだけで無停電を保証するものではありません。

## 実装部品と未確定事項

| 部品 | 現在の図面上の値・用途 | 使用前に確認すること |
| --- | --- | --- |
| D1 | RBQ30NS65ATL／2入力のダイオードOR | 放熱、実負荷での電圧降下・温度 |
| F1・F2 | 各入力のヒューズ | 定格電流・定格電圧・遮断容量・突入への適合 |
| C1 | 4700 µF／出力平滑 | 耐圧・極性・リプル電流、接続時の突入電流 |
| C2 | 1 µF／出力デカップリング | 耐圧、実使用電圧での容量 |
| C3 | 0.1 µF／出力デカップリング | 耐圧 |
| D4 | SMBJ26A／OUT–GND間のTVS | サージ時のクランプ電圧と後段機器の許容電圧の整合 |
| D2・D3・D5 | 入力・出力表示用LED | LEDの型番・極性 |
| R1～R3 | LEDの直列抵抗（値未指定） | 抵抗値・許容損失 |

D4はサージ抑制用です。OUTを常に26 V以下に保つ回路や、過電圧で給電を切断する回路ではありません。設計メモにある「DC/DC入力上限30 V」は未確認情報のため、使用するDC/DCの資料で確認してください。

D1は出力から入力側への逆流を抑える構成ですが、入力の逆接続保護を保証するものではありません。バッテリーは必ず極性を確認して接続してください。

## 困ったとき

| 症状 | 確認する箇所 |
| --- | --- |
| 片側の入力LEDが消えている | 対応する電池・配線・F1/F2・LEDと抵抗の実装 |
| 入力LEDは点くがOUTが出ない | D1の向き・はんだ付け・OUT配線・負荷の短絡 |
| OUTは出るがPCが動かない | DC/DCの入力範囲、出力電圧・極性・容量、PC側の電源仕様 |
| 電池を外すとPCが落ちる | 残る電池の電圧・供給能力、ヒューズ、接点、切替時の電圧低下 |
| 部品や配線が過熱する | 使用を止め、負荷電流・接触不良・放熱・短絡を確認 |
